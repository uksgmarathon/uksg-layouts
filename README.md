# uksg-layouts

> The on-screen graphics used during the UKSG (United Kingdom Speedrunner Gathering) events.

A [NodeCG](https://www.nodecg.dev/) bundle (used with [nodecg-speedcontrol](https://github.com/speedcontrol/nodecg-speedcontrol))
providing the omnibar, game layouts, intermission and countdown graphics, plus the dashboard panels that control them.

## Documentation

- **[User guide](docs/user/README.md)**: for hosts, producers and tech crew running the stream.
- **[Developer guide](docs/dev/README.md)**: for installing, configuring, deploying and developing the bundle.

Start at [docs/README.md](docs/README.md) if you're not sure which you need.
