# UKSG Layouts documentation

These are the on-screen graphics (and the dashboard that controls them) used during UKSG events.
They run as a bundle inside [NodeCG](https://www.nodecg.dev/) alongside [nodecg-speedcontrol](https://github.com/speedcontrol/nodecg-speedcontrol).

## Which docs do I need?

**I'm hosting, producing or running the stream on the day** → [User guide](user/README.md).
No technical knowledge needed; it explains what's on screen and how to control it from the dashboard.

**I'm setting it up, changing the code, or fixing something that's broken** → [Developer guide](dev/README.md).
Covers installing, configuring, deploying and developing the bundle.
